How to get around it

Android

Settings → Network & internet → Private DNS → "Private DNS provider hostname" → enter one.one.one.one (or dns.google).

Samsung: Settings → Connections → More connection settings → Private DNS.

iPhone / iPad

Install Cloudflare's free 1.1.1.1 app from the App Store, open it, and switch it on. The default "1.1.1.1" mode encrypts your DNS.

Windows 11

Settings → Network & internet → Wi-Fi (or Ethernet) → Hardware properties → DNS server assignment → Edit → Manual.

Turn on IPv4. Preferred DNS 1.1.1.1, alternate 1.0.0.1. Set DNS over HTTPS to "On (automatic template)".

Mac

Easiest: install the 1.1.1.1 app for macOS, or use the browser settings below.

Chrome / Edge / Brave

Settings → Privacy and security → Security → Use secure DNS → pick Cloudflare (1.1.1.1).

Firefox

Settings → Privacy & Security → DNS over HTTPS → Max Protection → Cloudflare.

Some of it is blocked past DNS, so changing DNS won't be enough. Use a VPN: turn on WARP in the free 1.1.1.1 app, or use Proton VPN's free plan.

DNS servers tested

Tested from a home connection. "Plain" is regular DNS. DoT and DoH are encrypted DNS, which is harder for the ISP to tamper with.
